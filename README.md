A poster for a place that doesn't exist: **ONDARA** — where the falls rise
from the sea, up through a giant stone arch, into the dusk clouds.

Entry for the make.fun bounty:
[the-poster-for-a-place-that-i-2-20261121-0539](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539)

## Run

```sh
python3 main.py
```

Pure Python 3 stdlib only — no dependencies, no network. Writes the poster
to `/output/entry.png` (1024×1024, deterministic: byte-identical on every run).

## The poster

- Dusk sky: indigo → purple → pink-orange, thin cloud bands, stars
- **ONDARA** in huge smooth gold serif (vector letterforms, 2× supersampled)
- One giant stone arch framing the **rising** waterfall: foam ring at the
  sea base, pale column rising through the arch, spray and golden droplets
  dissolving into mist at the top
- Houses with warm lit windows on the arch crown and cascading down the
  left hillside, string lights between them
- Teal sea with a glittering light-path and two sailboats
- Foreground terrace: a couple from behind (red dress + straw hat, white
  shirt), a table with two wine glasses and a bottle, pink bougainvillea
